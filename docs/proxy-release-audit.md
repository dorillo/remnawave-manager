# Аудит прокси сайтов 1–7

Проверены маршруты API и изображений, генерация и обновление nginx, новая установка,
локальные preview-серверы, CSP и обновление JavaScript-модулей. Предыдущие изменения
сохранены; производственная архитектура остаётся статическими файлами и nginx.

Исправления:

- При новой установке Node копируются все общие модули, включая `image-proxy.js`,
  и версионируется вся цепочка импортов. Ранее этот путь установки пропускал модуль.
- Все прокси получили общую политику TLS, запрета перенаправлений и кеширования.
  Внешние `X-Accel-*` не управляют nginx, cookies и перенаправления не попадают
  клиенту. MIME, CSP sandbox и nosniff предотвращают исполнение содержимого
  внешнего источника как кода сайта.
- Прокси изображений ограничен путями изображений, а не любым путём разрешённого
  домена. Сохранены Unicode, параметры CDN, SVG, формулы Wikipedia и аватарки Mail.
- Существующие известные конфигурации обновляются без повторных location-блоков;
  повторное применение не меняет уже обновлённую конфигурацию.
- Preview Aster сохраняет номер страницы поиска. Исправлены исчезновение ответов
  при одновременной загрузке комментариев и раскрытие сохранённых комментариев
  при недоступности API.
- Preview-серверы не выдают листинги каталогов, скрытые файлы и внешние символические
  ссылки, включая ссылки из index.html/index.htm. Добавлены таймаут соединения,
  ограничение размера ответа изображений и единые заголовки ошибок без кеширования.
  Ограничения локальных пользовательских загрузок Loop не изменялись.

Проверки в рабочей macOS-среде:

- 41 профильный Python-тест прошёл: интеграции семи сайтов, установка, миграции,
  маршруты, статические ресурсы и настоящий nginx с подставным внешним сервером.
- `nginx -t` прошёл для всех семи групп вместе, с настоящими доменами и системным
  CA-файлом macOS вместо производственного пути Linux.
- Браузерные сценарии всех семи сайтов прошли. Отдельно прошли проверки изображений,
  устаревшего HTTP-кеша модулей, комментариев Aster и безопасности медиа через
  настоящий HTTP preview-сервер.
- В полном Python-прогоне: 744 теста, 45 failures, 5 errors, 2 skipped.
  Сравнение с чистым HEAD (730 тестов) подтвердило те же 50 неуспешных тестов,
  без новых сбоев. Полный прогон в этой среде не является зелёным: остаются
  существующие несовместимости тестов с macOS/непривилегированным запуском,
  включая `/dev/shm`, права root и проверки marker-файлов Certbot.

Это локальная проверка, без развёртывания на рабочем сервере и без нагрузочного
тестирования. После обновления нужно перезапустить preview; для production —
повторно применить шаблон штатным способом, чтобы обновились nginx и статика.
Команды просмотра и внешние зависимости описаны в [инструкции](disguise-image-proxy.md).

Основание обработки управляющих заголовков:
[документация nginx, proxy_ignore_headers](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_ignore_headers).
