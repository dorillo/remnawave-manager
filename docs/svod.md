# Свод — энциклопедия (`05-field-notes`)

Статическое приложение для чтения энциклопедии: поиск, полные статьи,
оглавление, сноски, категории, случайная статья, печать и настройки чтения.
Интерфейс русский и английский; статьи остаются на русском языке.
Локальный аккаунт открывает библиотеку, коллекции и историю с продолжением чтения.
Социальных функций и редактирования источника нет.

Правило дальнейшей переработки сайтов: backend не пишем. Текущие исправления
интерфейса ограничены статическим фронтендом; серверные маршруты не меняются.

## Источник контента

Источник — русская Википедия, `https://ru.wikipedia.org/w/api.php`.
Приложение использует анонимное чтение MediaWiki Action API. Поиск, полные
статьи, категории и случайные статьи загружаются через ограниченный прокси.
Тексты не переводятся при переключении интерфейса на английский.

Рендерер проверен на полноразмерных статьях «Земля», «Россия»
(перенаправление «РФ»), «Эйнштейн, Альберт», «Теорема Пифагора» и «Лук».
Тестовые материалы не включены в приложение: контент поступает из API.
Живая проверка 17 сентября 2026 года через preview-прокси подтвердила поиск,
полный текст, категории и случайную статью. В браузере проверены реальные
изображения, внутренние ссылки и мобильная вёрстка. Доступность у каждого
провайдера отдельно не проверялась.

## Данные и хранение

API запрашивается анонимно через четыре ограниченных GET-маршрута Nginx:

| Маршрут | Операция MediaWiki |
| --- | --- |
| `/_svod/wikipedia/search?q=…&offset=0` | `query`, `list=search`, пространство статей |
| `/_svod/wikipedia/article?title=…` | `parse`, текст, категории, ID версии и перенаправления |
| `/_svod/wikipedia/category?title=…&continue=…` | `query`, `list=categorymembers` |
| `/_svod/wikipedia/random` | `query`, `list=random`, пространство статей |

Отдельного backend-приложения, базы на сервере или контейнера не требуется.
Nginx проверяет параметры, использует фиксированный upstream, проверяет TLS,
не передаёт пользовательские cookies, Authorization и тела запросов.
Изменять статьи через эти маршруты нельзя.

Профили, библиотека и история хранятся в IndexedDB `svod:wikipedia:v1`, отдельно для
каждого аккаунта. Сессия — в localStorage, настройки — в localStorage.
Пароли хэшируются PBKDF2-SHA256 с индивидуальной солью, 210000 итераций.
Для Web Crypto требуется HTTPS либо localhost. Это локальный профиль,
а не защита от владельца браузера: синхронизации и восстановления через почту нет.
Очистка данных сайта удаляет профили и личные данные.

Библиотека хранит закладки, а не постоянные офлайн-копии. Кэш последних статей
отделён от личных данных: до 30 записей и около 20 МиБ, допустимый возраст
сохранённой копии при сетевой ошибке — семь дней. Кэширование может не выполниться
при нехватке места; успешное чтение от этого не зависит. Старая копия помечается
датой. Офлайн-загрузка всех изображений не гарантируется.

## Отображение и безопасность

Внешний HTML очищается локальной DOMPurify 3.4.15 по списку разрешённых тегов
и атрибутов. Исходные JavaScript, стили, формы, фреймы и обработчики событий
не выполняются. ID из статьи отделены от элементов приложения; внутренние
ссылки и сноски переписываются в маршруты читателя. Изображения разрешены
только с перечисленных в CSP HTTPS-доменов. Формулы отображаются через
MathML без загрузки внешнего исполняемого кода.

Широкие таблицы прокручиваются внутри статьи. На телефоне инфобоксы занимают
одну колонку, оглавление раскрывается отдельно. Есть светлая, тёмная и системная
темы, два размера текста, выбор ширины колонки, клавиатурная навигация и печать.

Сведения о происхождении и лицензировании материалов сохранены в документации
дистрибутива и `NOTICE`; пользовательский интерфейс их не показывает.
Лицензия DOMPurify включена рядом с модулем: `DOMPurify-LICENSE.md`.

## Просмотр и установка

Live Server раздаёт оболочку, но не создаёт API-маршруты. Для полноценного
просмотра из корня репозитория:

```sh
python3 scripts/preview_svod.py
```

Адрес по умолчанию — `http://127.0.0.1:5505/`.
Скрипт использует только стандартную библиотеку Python, раздаёт каталог пятого
сайта и выполняет те же ограниченные запросы. Для остановки — Ctrl+C.

Установка выполняется штатно:

```sh
sudo rwm disguise apply 05-field-notes
```

Файлы, маршруты Nginx и инвентарь обновляются одной транзакцией с резервной копией
и откатом при ошибке. Другие API-маршруты и пользовательские конфигурации
не заменяются вслепую. Сервер просмотра после разработки не оставляется запущенным.

## Проверки

```sh
PYTHONPATH=src python3 -m unittest \
  tests.test_svod_integration tests.test_disguise tests.test_disguise_sites \
  tests.test_packaging tests.test_aster_integration \
  tests.test_morrow_integration tests.test_answers_integration -q
node tests/svod.browser.cjs
```

Браузерные проверки используют `tests/.tmp/node_modules/playwright-core` и
установленный Chrome; путь можно задать через `SVOD_BROWSER`.
Проверяются аккаунты и их изоляция, коллекции, история, повторный вход,
ошибочный пароль, удаление профиля, навигация, сноски, категории, RU/EN,
ширины 320/375/768/1024/1440 px, печать, кэш и очистка опасного HTML.

Дополнительная проверка больших реальных ответов API:

```sh
SVOD_CONTENT_DIR=/path/to/parse-json node tests/svod.content.browser.cjs
```

JSON-файлы должны содержать ответы `action=parse` с полем `text`; тест не
включает их в дистрибутив. На macOS для Python-проверок следует использовать
TMPDIR без symlink-компонентов. Общий Linux-тест установки Node требует
`/dev/shm` и не проходит на macOS без соответствующего окружения.

Живая проверка (требует доступа к Википедии):

```sh
node tests/svod.live.cjs
```

Тест временно запускает preview на свободном локальном порту и останавливает
его при завершении. Сервер для пользовательского просмотра не оставляется.

## Проверка интерфейса 17 сентября 2026 года

Поиск перенесён в шапку и остаётся единственным на всех страницах, текстовые
пиктограммы заменены локальными SVG. Состояния загрузки центрированы, вход размещён внутри
приглашения в библиотеке и истории, обе кнопки формы аккаунта выровнены.
Заголовки и текст продолжаются рядом с высоким инфобоксом; вложенные таблицы
не получают лишние контейнеры прокрутки. На узком экране инфобокс занимает всю ширину.

Исправлены сброс мобильного меню при переходах, фокус при смене формы,
повторные нажатия сохранения, восстановление кнопки после ошибки подтверждения,
видимость уведомлений внутри диалогов и светлая палитра при печати из тёмной темы.
Диалоги получили доступные названия и блокируют прокрутку фоновой страницы.
Ctrl/Cmd+K фокусирует единственное поле поиска, не уводя фокус из открытого диалога.
Мобильная навигация выезжает слева поверх затемнённой страницы и переводит
фокус на первый пункт. Действия над коллекцией находятся в меню
`⋯` рядом с её вкладкой. Оглавление статьи подсвечивает текущий раздел при прокрутке.
На экранах до 900 CSS-пикселей инфобоксы и иллюстрации переходят в одну колонку,
чтобы высокие боковые блоки не оставляли пустые области. Поиск центрирован
относительно окна. Выход из аккаунта и удаление сохранённой статьи требуют
подтверждения; подтверждение удаления аккаунта сохранено.

Браузерный сценарий проверяет поиск, загрузку, формы и библиотеку, высокий
инфобокс, навигацию, локальные аккаунты, очистку опасного HTML, ошибки,
RU/EN, темы и печать. Главная проверена на 320/375/600/768/1024/1440 px,
статьи — на 320/375/768/1024/1440 px. Пять сохранённых полных ответов Википедии
проверены на 320/768/1440 px; изображения в этом прогоне подменены заглушками.
Это проверка фронтенда и его регрессий, а не аудит серверной инфраструктуры
или подтверждение отсутствия всех возможных уязвимостей.

Сессия сохраняется после закрытия браузера. При первом открытии прежняя сессия
из хранилища вкладки переносится автоматически. Выход выполняется явно через интерфейс.
