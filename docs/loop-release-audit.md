# Loop: предрелизный аудит

Дата: 18 сентября 2026. Область: сайт `06-loop-archive`, его фронтенд,
упаковка и существующая интеграция получения медиа. Сайты 1–5 и другие проекты
не изменялись. Бэкенд не добавлялся; ограничения размера загружаемого файла нет.

## Исправления

| Проблема | Исправление |
| --- | --- |
| Открытие собственного материала автоматически отправляло его название/тег во внешний поиск | Внешние рекомендации используют тип и категорию; сопоставление собственных материалов по тегам остаётся внутри приложения. Явный поиск пользователя сохранён. |
| Недоступность IndexedDB блокировала публичную ленту | Публичные страницы продолжают работать без личной библиотеки; ошибка показывается отдельно. |
| Неудачное открытие IndexedDB могло оставлять отвергнутый Promise или лишнее соединение | Состояние соединения сбрасывается; запоздалое открытие после `blocked` закрывается. |
| Устаревшая форма профиля могла восстановить удалённый аккаунт | Имя обновляется транзакционно только для существующего текущего аккаунта. Устаревшая сессия очищается. |
| Параллельное создание/переименование коллекций допускало одинаковые имена | Проверка уникальности и запись выполняются в одной транзакции. |
| После удаления аккаунта могла оставаться возможность записать новый лайк | Транзакция проверяет существование аккаунта и текущую сессию. |
| Кэш ленты мог сохранять карточку материала, удалённого в другой вкладке | При следующем отображении страницы проверяется актуальный список своих материалов; изменившийся список сбрасывает кэш. |
| Сетевой сбой мешал показать карточки из уже загруженного буфера | Буфер отображается независимо от отказа следующего запроса; повтор загрузки остаётся доступен. |
| Экстремальные пропорции изображений могли давать отрицательную ширину колонок | Добавлен переход к равной ширине колонок для таких наборов; обычная плотная раскладка с ровным низом сохранена. Числовые размеры из источника нормализуются. |
| Поздний ответ сети сбрасывал прокрутку, сделанную пользователем | Позиция восстанавливается только если пользователь не прокрутил страницу за время загрузки. Кэш позиций ограничен по количеству маршрутов. |
| При прямом открытии категории оставался общий заголовок | Название обновляется после получения категорий. Поиск и категория согласованы с существующими раздельными режимами источника. |
| Явное включение анимаций забывалось при перезагрузке с системным reduced motion | Сохранённый выбор пользователя имеет приоритет; системная настройка используется по умолчанию. |
| Декодер GIF недостаточно проверял повреждённые данные | Проверяются заголовок, размеры, границы кадров/палитр, коды и цепочки LZW, чтение за границей данных. Ограничения размера файла не добавлялись. |
| Ошибка декодирования готовой видеоверсии оставляла плеер без восстановления | Появляется повтор подготовки; повреждённый кэш сбрасывается, предыдущий Blob URL освобождается. Стандартный видеоплеер сохранён. |
| Некоторые поля могли вызывать автоматическое увеличение на iOS; длинный заголовок диалога сжимал закрытие | Мобильные select/textarea используют шрифт 16 px; заголовок переносится, кнопка закрытия не сжимается. |

## Проверки

- `node tests/loop.browser.cjs` и вариант с `LOOP_ENGINE=webkit`:
  маршруты, поиск, фильтры, пагинация, лайки, коллекции, профиль, ошибки сети,
  отсутствие хранилища, транзакционные гонки и устаревший аккаунт.
- `node tests/loop.uploads.cjs` и вариант с `LOOP_ENGINE=webkit`:
  GIF, статические и GIF-стикеры, клипы, повторное открытие, исходные скачанные байты,
  встраивание, удаление с очисткой ссылок, границы владения, миграция хранилища,
  загрузка файла больше 50 MiB без ограничения приложения.
- Для GIF проверены реальные разные кадры, штатные controls, конечная длительность,
  запуск, пауза, перемотка, повтор после ошибки и отказ на повреждённых заголовках.
- Проверены исходящие запросы: файлы и служебные идентификаторы загруженных материалов
  не отправляются в сеть; открытие своих материалов не отправляет их названия/теги.
- Проверены ограничения URL источника, отказ SVG/HTML под видом загружаемых файлов,
  вставка текста через DOM, отсутствие ошибок JavaScript и нарушений CSP в сценариях.
- Ширины 320–1920 px, обе темы и языки; отдельная сенсорная эмуляция,
  портрет 320×568 / 390×844 и горизонтальный режим 844×390, формы и нижнее меню.
  Скриншоты реального контента и форм просмотрены вручную.
- `node tests/loop.live.cjs`: реальный поиск, медиаданные, скачивание, страница
  материала и низ ленты GIF/стикеров/клипов. Временный сервер предпросмотра остановлен тестом.
- 23 проверки Python: `tests.test_loop_integration`, `tests.test_disguise_sites`,
  `tests.test_disguise`, `tests.test_packaging`.

## Границы проверки

Проверки Chrome и WebKit автоматизированы; физических iPhone/Android в этой сессии
не было. WebKit проверяет тот же класс браузерного движка, но не заменяет тестирование
конкретной версии Safari на устройстве. Доступность внешнего источника зависит от него;
ошибки и повтор загрузки предусмотрены. Первая подготовка GIF-видеоверсии по-прежнему
занимает примерно длительность одного цикла анимации. Серверной авторизации в проекте
сайта нет; аудит не добавляет её и не приписывает фронтенд-профилю серверные гарантии.

В проверенных сценариях блокирующих ошибок после исправлений не обнаружено.
