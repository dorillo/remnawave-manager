# Исправления интерфейса сайтов 1–7

Исправлены замечания пользователя:

1. **Line:** пустые состояния, поля редакторов, уведомления, кнопки и мобильная
   навигация используют цвета выбранной темы. Устранены белые блоки со светлым
   текстом; повышен контраст второстепенного текста в светлой теме.
2. **Morrow:** после успешной загрузки пустого обсуждения появляется
   «Комментариев пока нет. Начните обсуждение». Ошибка API отображается отдельно.
3. **Spros:** «Мои вопросы» требует входа и показывает вопросы текущего аккаунта.
4. **Spros и Fokus:** гость может написать ответ/комментарий; отправка открывает
   авторизацию. Черновик сохраняется при закрытии окна и после входа. Для публикации
   после входа пользователь снова нажимает отправку.
5. **Все семь:** убрано подчёркивание ссылок и кнопок, включая их вложенный текст.
   Сохранены остальные эффекты наведения и обозначение клавиатурного фокуса.
6. **Заголовки вкладок:** название сайта стоит перед разделом. У новости Fokus
   остаётся только заголовок новости. Исправлены и стартовые HTML-заголовки Line
   и Morrow, чтобы порядок не менялся во время загрузки JavaScript.
7. **Первый экран:** оболочка с навигацией отображается до данных. Убрано ожидание
   IndexedDB перед первой отрисовкой Loop и Fokus. Во время чтения хранилища
   Morrow, Loop и Svod виден индикатор загрузки.
8. **Загрузка:** вместо текстовых индикаторов добавлены вращающиеся кружки на
   страницах, в обсуждениях, при загрузке файлов и подготовке GIF-плеера Loop.
   Существующие анимированные заглушки карточек сохранены. Подписи доступны
   скринридерам; при `prefers-reduced-motion` вращение отключено.

Дополнительные найденные проблемы и улучшения:

- Spros показывал в «Моих вопросах» публикации всех сохранённых аккаунтов,
  а не только текущего. Исправлена фильтрация, проверена смена аккаунтов.
- Открытие окна входа в Spros уничтожало черновик формы. Теперь сохраняются
  текст и выбранные вложения; черновики не переносятся при смене одного
  авторизованного аккаунта на другой.
- В Spros фокус клавиатуры выходил за границы модального окна и терялся после
  закрытия из-за перерисовки DOM. Добавлены удержание/возврат фокуса, отключение
  фоновых элементов и фоновой прокрутки. При смене аккаунта устаревшее окно
  редактирования закрывается. В основной форме ответа добавлен вывод ошибок вложений.
- Профиль Aster и приглашение войти зависели от доступности общего каталога.
  Теперь их можно открыть, пока каталог загружается или недоступен.
- Morrow скрывал уже сохранённые комментарии до завершения сетевого запроса.
  Теперь они отображаются сразу, а полученные страницы добавляются по мере загрузки.
- Для общей анимации добавлены `shared/feedback.js` и `shared/feedback.css`.
  Все preview-скрипты обслуживают их через общий обработчик с закрытым списком
  допустимых файлов. Проверена и установка шаблонов с этими ресурсами.

Предпочтения о пометках локального профиля и ссылках на исходные платформы
зафиксированы в `AGENTS.md`. Существующие изменения прокси сохранены.

## Проверки

- Основные браузерные сценарии всех семи сайтов: авторизация, смена аккаунтов,
  публикации, комментарии, реакции, поиск, хранилище, обработка ошибок и XSS.
- `ux-audit.browser.cjs`: все семь сайтов в Chromium, Firefox и WebKit, задержанные
  ответы API и файлов каталога, навигация до данных, заголовки вкладок, светлая
  и тёмная темы, ширины 320/390/768/1024/1440/1920, отсутствие подчёркивания,
  режим уменьшенной анимации.
- `site-chrome.browser.cjs`: язык и системная тема, восстановление настроек,
  размеры управляющих кнопок, геометрия видео Morrow в трёх браузерных движках.
- Отдельные регрессии Morrow/Aster для комментариев; Fokus для парсинга,
  санитизации и веток обсуждения; тесты изображений, CSP и обновления модулей.
- 42 профильных Python-теста прошли. Проверены все цепочки импортов и CSS
  preview-скриптов, копирование шаблонов и работа прежних прокси.
- Все семь preview-серверов проверены через настоящий HTTP: HTML и общие
  JS/CSS возвращаются успешно с `Cache-Control: no-store`.
- Полный Python-прогон: 745 тестов; 45 failures, 5 errors, 2 skipped.
  Идентификаторы всех 50 неуспешных тестов совпадают с предыдущим аудитом
  в этой macOS-среде; новых сбоев нет.

Проверки выполнялись локально с контролируемыми API-ответами. Для просмотра
изменений перезапустите `scripts/preview_*.py` и обновите страницу.
