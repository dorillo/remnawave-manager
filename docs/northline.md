# Line: интерфейс Mastodon (`01-northline`)

Статический интерфейс без сборки и собственного сервера приложений. Сайт читает
русскоязычные публикации выбранных авторов `mastodon.ml` через nginx своего
сервера; токен для просмотра не нужен. В браузере
можно создать локальный профиль: он открывает интерактивные действия Line,
но не предоставляет доступ к аккаунту Mastodon.

## Что реализовано

- Обзор из тематических подборок авторов: фотография, творчество, природа, книги;
  город и технологии можно включить в интересах. Дубликаты удаляются, авторы
  чередуются; отмеченные API боты скрыты в обзоре, но доступны на страницах тем.
- Русскоязычные публикации, пагинация каждого источника, проверка новых записей без сдвига
  читаемой ленты. Новые записи появляются после нажатия кнопки.
- Абзацы, ссылки, хештеги, упоминания, галереи, видео, аудио, карточки ссылок,
  опросы, предупреждения о содержимом и чувствительные медиа.
- Профили с обложкой, описанием, полями, счётчиками, закреплёнными публикациями,
  страницами записей и медиа. Отдельная загрузка контекста обсуждения.
- Темы и рекомендации реальных авторов. Гостевой поиск использует API и при его
  ограничении ищет среди уже загруженных данных.
- Локальная регистрация и вход, визуальный профиль, аватар и выход. Гости могут
  читать ленту, а профиль открывает реакции, комментарии, подборки, закладки,
  избранное, черновики и собственные истории. В историю можно добавить до
  четырёх собственных фото или видео; изображения оптимизируются в браузере.
- Комментарии длиной до 5000 символов поддерживают до четырёх фото или видео,
  вложенные ответы, лайки, репосты, сохранение, прямые ссылки и упоминание
  адресата. Локальные и публичные ответы выводятся в одном дереве и используют
  одинаковое оформление.
- Страница «Профиль» содержит отдельные вкладки публикаций,
  репостов, лайков, сохранённых публикаций и черновиков. Репосты публикаций и
  комментариев появляются во вкладке профиля; выход выполняется только после
  подтверждения.
- В форме входа регистрация открывается отдельной кнопкой; ошибки логина и
  пароля показываются внутри формы, а не во всплывающем сообщении.
- Фото профиля загружается с устройства и оптимизируется в браузере; поле со
  ссылкой на аватар больше не используется.
- Все действия Line привязаны к созданному в браузере профилю: несколько
  локальных аккаунтов не смешивают свои коллекции, реакции и черновики.
- Мобильная навигация, управление диалогами с клавиатуры, reduced-motion,
  состояния загрузки, ошибки источников и последняя сохранённая лента.
- Русский и английский языки интерфейса переключаются независимо от контента.
  Фильтра языка публикаций нет: в новых лентах показываются русские записи. При первом открытии русский выбирается для системной
  локали `ru`, во всех остальных случаях используется английский; выбор
  сохраняется для следующих посещений.

Подборка автора, реакции, комментарии, голосование и собственные истории
локальны: они не меняют счётчики и не появляются в Mastodon. Комментарии
показываются в Line на этом устройстве. OAuth и отправка публикаций в
Mastodon не входят в эту версию.

## Файлы и хранение

- `app.js`: маршруты, экраны и действия.
- `northline-data.js`: API, нормализация, темы, пагинация и кэш запросов.
- `northline-ui.js`: DOM-компоненты, SVG-иконки, безопасный вывод HTML и диалоги.
- `northline-i18n.js`: автоопределение и переключение русского/английского
  интерфейса, словарь и форматирование динамических подписей.
- `northline-store.js`: данные активного локального профиля, коллекции,
  настройки, черновики и истории.
- `northline-auth.js`: локальные аккаунты, парольный хэш и сессия браузера.

Внешний HTML перестраивается по разрешённому набору элементов. Удаляются
обработчики событий, скрипты, формы и встраивания; ссылки разрешены только HTTPS.
Вызовы API проходят через фиксированные маршруты своего сайта. Новые ленты
используют `mastodon.ml`, старые сохранённые ссылки — `mastodon.social`. Тайм-аут запроса — 12 секунд; при 429
учитывается `Retry-After`. Не более трёх API-запросов выполняются одновременно.
API-кэш ограничен количеством ключей; устаревшие ответы используются до семи
дней с уведомлением. Последняя лента и сохранённые записи хранятся отдельно.
Ошибки localStorage не мешают чтению, неуспешное сохранение показывается пользователю.
Это не защита учётной записи: данные можно прочитать или изменить через DevTools,
а очистка данных сайта удалит профили. Для настоящих аккаунтов нужен серверный
backend.

## Источники и совместимость

`TOPIC_AUTHORS` в `northline-data.js` содержит идентификаторы авторов на
`mastodon.ml`, распределённые по интересам. Это подборки авторов, а не строгая
классификация каждой их записи. Общая публичная лента и ленты хештегов этого
сервера требуют авторизации и не используются. Произвольный хештег ищется
среди публикаций выбранных авторов. Поиск API выполняется без `resolve`; при
отказе гостевого доступа сохраняется поиск среди уже загруженных данных.

Язык `ru` принимается из API. При отсутствующей метке применяется осторожная
эвристика по тексту; она не гарантирует определения языка каждого короткого
сообщения. Явные метки других языков исключаются. Исходные обсуждения и ранее
сохранённые записи остаются доступны в оригинале; автоматического перевода нет.

«Ваши авторы» показывает только собственные русскоязычные публикации подписок.
API получает `exclude_reblogs=true`; клиент дополнительно проверяет автора и
отсутствие репоста. Курсор берётся из исходного ответа до фильтрации. В профилях
и тематических подборках репосты по-прежнему доступны. Ручное обновление ленты
подписок обходит API-кэш. При смене локального профиля или подписок лента
пересоздаётся, а запоздавшие ответы прежней ленты игнорируются.

Идентификаторы новых постов и авторов имеют префикс `ml:`, старые числовые ID
по-прежнему относятся к `mastodon.social`. Старые закладки, реакции, подписки,
локальные профили и комментарии не удаляются. API-кэш и последняя лента нового
источника хранятся отдельно от старых. Курсоры рассчитываются до языковой
фильтрации; при частичном отказе источников курсор не продвигается.

## Установка и CSP

HTML разрешает API-запросы только к своему origin. Изображения загружаются через `/_images/`, видео —
по HTTPS из медиахранилищ источников; для собственных вложений разрешены
`data:` и `blob:`. Переключатель языка интерфейса сохраняет прежнее поведение.

`rwm disguise apply 01-northline` устанавливает файлы и фиксированные маршруты
`/_northline/mastodon/api/…` в управляемую конфигурацию nginx. Для старых записей
добавляются маршруты `/_northline/legacy/api/…`, ограниченные чтением профилей,
публикаций и обсуждений. Проверка хеша конфигурации, backup, nginx test и откат
при ошибке используют существующий механизм установки шаблонов.
Первая установка Node с комплектным шаблоном № 1 также подключает прокси.
Неизвестный CSP останавливает замену до согласования конфигурации.

`northline_proxy.py` задаёт общий разрешённый набор маршрутов и параметров для
nginx и предпросмотра. Разрешён только GET, адреса upstream фиксированы,
пользовательские заголовки и тело не передаются, TLS-сертификаты проверяются,
редиректы не пропускаются. Произвольных адресов, токенов и операций записи нет.

## Локальный просмотр

Обычный Live Server не предоставляет API-прокси. Из корня репозитория:

```sh
python3 scripts/preview_northline.py
```

Открыть `http://127.0.0.1:5501/`. Другой порт: `--port 5511`.
Скрипт использует только стандартную библиотеку Python, по умолчанию слушает
loopback, обслуживает сайт и нужный общий модуль, ограничивает размер ответа
API шестью MiB и не следует редиректам. Авторизация в Mastodon не нужна.

## Проверки без сервера просмотра

Python-проверки запускаются штатным `unittest` из корня проекта:

```powershell
$env:PYTHONPATH = 'src'
python -m unittest discover -s tests -q
```

Браузерные проверки используют headless Chromium. Статические файлы подаются
перехватом запросов в памяти; HTTP-сервер не запускается. Зависимости и снимки
находятся в игнорируемой папке `tests/.tmp`:

```powershell
npm install --prefix tests/.tmp --no-save --no-package-lock playwright-core@1.63.0
node tests/northline.browser.cjs
```

По умолчанию используется установленный Chrome в Windows. Другой Chromium можно
указать переменной `NORTHLINE_BROWSER` (путь к исполняемому файлу).
Для проверки с реальным API вместо фикстур:

```powershell
$env:NORTHLINE_LIVE = '1'
node tests/northline.browser.cjs
Remove-Item Env:NORTHLINE_LIVE
```

Документация API: [ленты](https://docs.joinmastodon.org/methods/timelines/),
[статусы и обсуждения](https://docs.joinmastodon.org/methods/statuses/),
[профили](https://docs.joinmastodon.org/methods/accounts/),
[медиа](https://docs.joinmastodon.org/entities/MediaAttachment/).

## Развёртывание через менеджер

Чистая установка использует `rwm install node --template 01-northline` вместе
с обязательными параметрами ноды и сертификата. На существующей ноде применяется
`rwm disguise apply` с тем же ID. Оба пути устанавливают общие модули, версии
ресурсов и nginx-маршруты. Условия совместимости, CDN, XHTTP, WARP, Subscription
Page и откат описаны в [руководстве по развёртыванию](node-sites.md).

Сессия сохраняется после закрытия браузера. Выход выполняется явно через интерфейс.
