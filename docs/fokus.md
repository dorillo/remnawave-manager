# Fokus — новости и обсуждения (`07-fokus-news`)

Статическое новостное приложение с контентом РИА. Название **Fokus** не меняется
при переключении языка. Интерфейс RU/EN, светлая и тёмная темы, адаптивная
вёрстка от 320 px. В production нужны только файлы сайта и существующий nginx.

## Возможности

- Главная с редакционными материалами РИА и хронологической RSS-лентой.
- Политика, мир, экономика, общество, наука и культура с загрузкой следующих страниц.
- Полные статьи, изображения, цитаты, связанные материалы и ссылка на оригинал.
- Шесть реакций РИА и внешние комментарии с контекстом ответов и пагинацией.
- Страница активных обсуждений; одна строка поиска по загруженным и сохранённым новостям.
- Локальные профили, аватары, закладки, история, свои комментарии и реакции.
- Локальные ответы на внешние и собственные комментарии, лайки, редактирование
  и удаление владельцем. Действия не отправляются в РИА.
- Смена темы и языка сохраняет черновик комментария. Контент источника остаётся
  на исходном языке. Диалоги работают с клавиатуры и закрываются по Escape.

## Источник и прокси

Используются анонимные маршруты веб-клиента РИА — RSS, JSON и HTML, а не
документированный API с гарантиями стабильности. HTML разбирает фронтенд.
Все внешние данные и изображения проходят через nginx:

| Маршрут приложения | Источник на ria.ru |
| --- | --- |
| `/_fokus/ria/feed` | `/export/rss2/archive/index.xml` |
| `/_fokus/ria/home` | `/` |
| `/_fokus/ria/section/{section}` | Фиксированная рубрика `/{section}/` |
| `/_fokus/ria/more/{section}?id=…&date=…[&view=tags]` | `/services/{section}/more.html` |
| `/_fokus/ria/article/{date}/{slug}-{id}.html` | Канонический адрес статьи |
| `/_fokus/ria/dynamics/{date}/{id}` | `/services/dynamics/{date}/{id}.html` |
| `/_fokus/ria/comments?article_id=…&limit=20[&date=…&date_usec=…&id_exc=…]` | `/services/chat/get/` |
| `/_fokus/ria/rooms` | `/services/chat/get_rooms/` |
| `/_fokus/media/images/{path}` | Фиксированный CDN `cdnn21.img.ria.ru` |

Текст, реакции и обсуждение запрашиваются при открытии статьи. Сбой социальной
части не блокирует чтение. Счётчик «Загружено комментариев» относится к реально
полученным сообщениям: `chat.total` РИА не используется как полный размер
обсуждения, поскольку меняется при запросе следующей страницы.

Реакции РИА и локальные реакции хранятся раздельно. Показанное число — известная
внешняя основа плюс локальные действия профилей браузера. Обновление источника
не удваивает и не стирает локальные действия. Неизвестное число обозначается
прочерком; локальная добавка при этом показывается отдельно.

Новости и изображения не входят в дистрибутив. Права остаются у правообладателей.
У материалов сохраняется источник и ссылка на оригинал.

## Хранение и безопасность

Профили и действия хранятся в IndexedDB `fokus:ria:v1`, сессия — sessionStorage,
язык и тема — localStorage. Пароли хэшируются Web Crypto PBKDF2-SHA256
(210000 итераций, индивидуальная случайная соль). Требуется HTTPS либо localhost.
Это локальные профили: очистка браузера удаляет данные, синхронизации между
устройствами и восстановления через почту нет. Владелец браузера может изменить
своё хранилище через инструменты разработчика.

Комментарии общие для профилей этого браузера. Закладки, история и выбранные
реакции привязаны к аккаунту. Удаление аккаунта очищает его персональные данные
и реакции, удаляет тексты его сообщений, сохраняя узлы для чужих ответов.

Прокси разрешает только конкретные GET-маршруты и параметры. Пути записи
недоступны, даже если исходный сайт вызывает их GET-запросом. Проверяются TLS
и SNI; cookies, Authorization и тела запросов не пересылаются. Редиректы,
Set-Cookie и Refresh скрываются. Ответы HTML отдаются как text/plain с nosniff
и CSP `default-src 'none'; sandbox`. Произвольный upstream задать нельзя.

Внешний HTML разбирается в инертном template. Скрипты, формы, iframe и стили
удаляются, текст и ограниченное форматирование заново собираются собственным
рендерером. URL валидируются; изображения переписываются на same-origin прокси.
Исходный DOM не подключается к документу. JSON комментариев нормализуется по
белому списку: служебные поля вроде IP адресов не сохраняются и не выводятся.
CSP приложения запрещает сторонние скрипты и подключения.

Кэш нормализованных внешних ответов ограничен 30 записями и примерно 20 МиБ
строковых данных. При ошибке доступна копия возрастом до 7 дней с датой
сохранения. Изображения офлайн не гарантируются. Локальные профили и действия
не удаляются при вытеснении кэша. Отказ хранилища не мешает чтению, но явно
сообщается при попытке сохранения.

## Локальный просмотр

Live Server раздаёт оболочку, но не создаёт прокси. Из корня репозитория:

```sh
python3 scripts/preview_fokus.py
```

Адрес: `http://127.0.0.1:5507/`. Можно задать `--host` и `--port`.
Скрипт использует стандартную библиотеку Python и тот же список разрешённых
маршрутов, что генератор nginx. Это инструмент разработки, в production он
не нужен. Остановка — Ctrl+C. После разработки сервер не оставлен работающим.

На node установка выполняется штатно:

```sh
sudo rwm disguise apply 07-fokus-news
```

Файлы, конфигурация nginx и inventory обновляются с резервной копией и откатом.
Другие сайты и пользовательские nginx-конфигурации не заменяются вслепую.

## Проверки

```sh
PYTHONPATH=src python3 -m unittest \
  tests.test_fokus_integration tests.test_disguise_sites tests.test_disguise \
  tests.test_packaging tests.test_northline_integration tests.test_aster_integration \
  tests.test_morrow_integration tests.test_answers_integration \
  tests.test_svod_integration tests.test_loop_integration -q
node tests/fokus.browser.cjs
node tests/fokus.live.cjs
```

На macOS для Python-тестов нужен TMPDIR без symlink-компонентов, например
`TMPDIR=/private/tmp/fokus-tests` после создания каталога. Браузерные тесты
используют `tests/.tmp/node_modules/playwright-core` и Chrome; исполняемый файл
можно указать через `FOKUS_BROWSER`.

Детерминированный браузерный сценарий проверяет два аккаунта, реакции и смену
внешних счётчиков, сохранение после перезагрузки, ответы, редактирование,
удаление аккаунта, поиск, RU/EN, темы, ширины 320/375/768/1024/1440,
недоступное хранилище, ошибки независимых панелей и отсутствие внешних записей.
Live-сценарий временно запускает preview, проверяет настоящую ленту, рубрику,
пагинацию, статью, реакции и комментарии; останавливает сервер в finally.

19 сентября 2026 года живые чтения проверены через preview и отдельный
временный nginx с проверкой TLS. `nginx -t` выполнен на локальном nginx;
для локальной проверки использован системный CA bundle Homebrew. В production
конфигурация использует `/etc/ssl/certs/ca-certificates.crt` контейнера.
Проверка на пользовательском node-сервере и у каждого российского провайдера
не выполнялась. Доступность самого ria.ru в РФ подтверждена пользователем.
